# Awesome Badges (archive)

Local mirror of GitHub project READMEs listed in
[badges/awesome-badges](https://github.com/badges/awesome-badges).

## Layout

```
awesome-badges/
├── README.md           # this file
├── _source-index.md    # original curated index
├── _repos.txt          # owner/repo entries extracted from the index
├── _success.txt        # successfully downloaded
├── _failed.txt         # failures (if any)
└── <owner>/
    └── <repo>/
        └── README.md
```

## Notes

- Organized by GitHub owner, then repository name.
- Non-GitHub links (websites, talks, articles, etc.) are not mirrored; see `_source-index.md`.
- `badges/shields` points at the deeper docs mirror in [`../shields/`](../shields/).
