# Awesome GitHub Profile READMEs (archive)

Local mirror of profile READMEs listed in
[abhisheknaiidu/awesome-github-profile-readme](https://github.com/abhisheknaiidu/awesome-github-profile-readme)
(Categories section).

## Layout

```
awesome-github-profile-readmes/
├── README.md           # this file
├── _source-index.md    # original curated index
├── _usernames.txt      # usernames extracted from Categories
├── _success.txt        # profiles with recovered README.md
├── _failed.txt         # profiles still unavailable
├── _recovered.txt      # alternate recovery sources
└── <username>/
    └── README.md       # that user's GitHub profile README
```

## Notes

- Snapshot taken from live `username/username` profile repos via the GitHub API.
- Some missing profiles were recovered via Software Heritage.
- Tools, articles, and tutorials from the source list are not mirrored.
