# Creative Profile READMEs (archive)

Local mirror of profile READMEs listed in the archived collection
[coderjojo/creative-profile-readme](https://github.com/coderjojo/creative-profile-readme).

## Layout

```
creative-profile-readmes/
├── README.md              # this file
├── _source-index.md       # original curated index from the archived repo
├── _usernames.txt         # usernames extracted from that index
├── _success.txt           # profiles with recovered README.md source
├── _failed.txt            # profiles whose README source is gone (preview only)
├── _recovered.txt         # alternate recovery sources for previously missing profiles
├── _previews/             # screenshot previews for unavailable README sources
└── <username>/
    ├── README.md          # profile README (or note + pointer if unavailable)
    └── preview.webp       # optional visual preview from the curated collection
```

## Notes

- Primary snapshot taken from live `username/username` profile repos via the GitHub API.
- Some missing profiles were recovered later via Software Heritage or the Wayback Machine.
- Entries in `_failed.txt` have only a visual preview (`preview.webp`); the original README source could not be retrieved.
