# Creative Profile READMEs (archive)

Local mirror of profile READMEs listed in the archived collection
[coderjojo/creative-profile-readme](https://github.com/coderjojo/creative-profile-readme).

## Layout

```
creative-profile-readmes/
├── README.md              # this file
├── _source-index.md       # original curated index from the archived repo
├── _usernames.txt         # usernames extracted from that index
├── _success.txt           # profiles successfully downloaded
├── _failed.txt            # profiles no longer available (repo missing/renamed)
└── <username>/
    └── README.md          # that user's GitHub profile README
```

## Notes

- Snapshot taken from live `username/username` profile repos via the GitHub API.
- Entries in `_failed.txt` had no reachable profile README repo at fetch time.
